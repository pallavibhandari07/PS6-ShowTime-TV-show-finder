# PS6 - ShowTime

ShowTime is a TV show finder built using React.
It allows users to browse TV shows, search by name,
filter shows by genre and view show details with cast information.

## Technologies Used

- React
- React Router DOM
- CSS
- TVMaze API
- Vite

## API Used

https://api.tvmaze.com

## Routes

| Route | Description |
|---|---|
| / | Home page |
| /shows | Browse and search shows |
| /shows/:id | Show details and cast |
| * | Page not found |

## Features

- Browse the first 40 TV shows
- Search for TV shows by name
- Filter shows by genre
- View show details and ratings
- View cast and character names
- Responsive design
